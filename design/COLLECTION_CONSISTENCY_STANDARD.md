# BuildinZ — Collection consistency standard

Owner direction: October 30, 2026. Apply consistency retrospectively to existing work and prospectively to all new collection production. Correct discrepancies under delegated creative authority, preserving original approved source assets.

## One naming system

Every final stage artwork must carry its exact canonical stage-specific building name mounted on the architecture. The website title, selector, preview, metadata and collector documentation must use that same name. Building type is a separate stable category, never a replacement for the stage name. Stage I / II / III is a separate stage label. Use one consistent geometric techno-luxury signage family, with coherent placement rules and neighborhood-specific accents.

Example: Residential is the type; Neon Residences, Skyline Habitat and Aurora Arcology are the respective stage names. All three must have their own matching stage-name sign. Do not mix a type-only artwork for one identity with stage-name artwork for another.

## Retrospective audit — required before launch

Audit every current and historical deliverable that might be presented as final: stage artwork, image exports, main website, previews, galleries, edition traits, metadata, roadmap, FAQ and descriptions. Retained historical snapshots may keep original wording only when clearly marked superseded and excluded from the release package.

Track each finding with identity, stage, artifact path, expected value, observed discrepancy, correction and verification status. Inspect actual image lettering visually; matching filenames is insufficient.

Check:
- Exact stage names, spelling and capitalization across every surface.
- Stable type and identity through all stages; no synonym renaming.
- Consistent signage font family, legibility, mounting and hierarchy.
- Complete silhouettes, safe framing, perspective, export quality and restrained landscaping.
- Distinct evolutionary silhouettes and stage-exclusive features, preserving approved architecture.
- Collection-wide rarity terminology, counts, edition numbering and trait definitions.
- Consistent treatment of implemented, simulated and future features.
- Canonical registry agreement with all website labels and token metadata.

Make corrected images versioned derivatives; retain originals. Do not silently replace approved architecture while repairing signage. Do not enable an artwork release gate until corrected assets and presentation have actually been verified.

## Production export policy — delegated decision, November 12, 2026

This operationalizes the existing standard; it is an agent implementation decision, not a historical owner approval. New final candidate exports use portrait 2:3 framing. Keep every architectural extremity (including antenna tips, roof overhangs and foundation) at least 3% of the respective image dimension inside the frame; landscaping may extend beyond this architectural safe area. Use versioned derivatives and background extension/reframing that preserves the building, never crop away structure to satisfy the margin. Existing images are not certified by adopting this rule.

Compare evolution within each identity using the same camera azimuth/elevation and a documented common foundation reference. Keep that reference within 5% display-width variation across the three-stage review, or record why a genuine expanded footprint requires an exception. Do not claim physical height measurements from image pixels. Stage growth must remain clear with preserved stage-exclusive program; equal canvas dimensions alone are insufficient.

Mounted signs use one uppercase geometric sans-serif techno-luxury treatment with consistent letter spacing, stroke weight and architectural mounting. Crimson accents remain warm gold on burgundy/charcoal backing. Preserve exact stage names; type and stage labels remain separate interface/metadata fields. Replace observed serif lettering only in versioned derivatives, preserving approved architecture. Review native resolution and 360px full-frame rendering for legibility before final certification. No edition finish expansion until corrected base lineage framing, signs and architecture pass actual visual review.
